# ULecture 使用与数据指南

## 开始使用

从 Release 安装 `ULecture.app` 后打开。在首次准备页检查本地资源；开始本地识别时校验并加载模型，成功后才显示就绪。启动本身不采集音频。十五秒试音是单独操作，请先选择音源并授予系统权限。

首次准备页会检查本地文件转换组件。若损坏，可选择同一构建的完整 ULecture.app，在本机验证并修复到受管目录；不自动联网或安装全局软件。

在工作空间新建课程，再通过导入文件或新建笔记、文件夹添加资料。新课程的存储目录由应用建立和管理，不再提供“打开课程文件夹”，也不支持选择任意目录直接载入内容。PDF、PPT、PPTX、Markdown、TXT 与 `.ulnote` 笔记登记后显示在侧栏；直接放入目录的未知文件或文件夹不会自动载入。

文件重命名、移动和导入会作用于真实文件。刷新会跟踪已登记资料的内容变化，以及在已登记位置内的改名、移动和删除；目录离线时保留身份并显示异常。移除课程只将其隐藏，可在设置中恢复已登记的课程，恢复入口不接受新目录。资料删除进入课程内部可恢复区域，在“最近删除”恢复。旧库迁移、课程重新定位和备份恢复继续保留；转写和应用资料目录仍受保护。

## 阅读、笔记与 AI

PDF 可阅读、缩放、旋转及使用高亮、下划线、删除线、画笔、橡皮、文本框、便签、矩形、椭圆、箭头。编辑器保存原件的固定版本和批注记录，导出标准批注 PDF 或扁平化 PDF；原课件不被直接覆写。PPT/PPTX 在本机转换为阅读 PDF，原始演示稿保留；格式限制见转换说明。

新笔记采用 `.ulnote` 文件包，包含文本、不可变历史版本和图片。支持标题、段落、列表、待办、图片、表格、引用和代码，保留不能安全转换的原 Markdown。Markdown/TXT 可直接编辑、预览和导出。保存失败时保留草稿并显示失败，退出会等待保存；存在无法保存内容时不会假报成功。

阅读页和课堂均可展开 AI 助手。勾选要使用的资料，可限定转写起止时间并选择已保存笔记版本，再解释选区、连续问答、生成笔记或总结。每次请求固定正文、版本、页码/块/时间与来源哈希；引用旧版本时展示固定来源。未勾选资料不会随该请求发送。生成结果需主动新建或追加到笔记；取消/失败保留已收到的部分文字。旧版总结及原始来源继续保留。

AI 资料中的扫描 PDF 在本机 OCR，选择英语或日语识别语言，逐页显示覆盖、置信度及缺失/失败。只有已提取并符合置信要求的文字进入来源快照；图片本身不会作为视觉理解请求上传。原生文本与扫描正文混合的页面也参与识别；空白或失败页不会伪造正文。

## 课堂与独立同传

课堂把课件、笔记与语音会话关联；资料可独立移动而保持稳定身份。课堂视图支持调整阅读/笔记/转写或AI面板；窄窗使用切换页。原文确认后才作为永久记录保存。暂停、设备故障和恢复的时间间断会保留。

独立同传无需先创建课程。每个会话自动维护两份 UTF-8 文件：`transcript.txt` 仅包含原文；`transcript-bilingual.txt` 包含原文与可正确关联的译文。同传页面的“原文 TXT”和“双语 TXT”分别在 Finder 中选中对应文件，无需手动导出。新建会话后选择音源和主要语言；开始采集、翻译、录音、回听及播报分别控制，录音和播报默认关闭。可将会话关联到课程，独立保存目录保持稳定。字幕浮窗可以跨应用显示、拖动、缩放，调整原文/译文行数、顺序、字号、颜色、透明度和置顶。关闭字幕不会结束同传。

同传模式可选择“本地识别＋在线文本翻译”“Google 在线同传”或“OpenAI 在线同传”。本地模式在本机识别英语或日语，翻译使用文本翻译服务；在线模式把所选音源发送至对应服务。在线同传默认使用独立凭据，也可在提供商一致时主动复用主 AI 服务的 Key。仅配置主 AI 服务并不等于已启用同传服务。Google 当前默认模型名称中的 Preview 是提供商的真实状态，不能视为稳定性承诺。账户、区域、费用和模型资格以 [Google 官方说明](https://ai.google.dev/gemini-api/docs/live-api/live-translate) 与 [OpenAI 官方说明](https://developers.openai.com/api/docs/guides/realtime-translation) 为准。

只有确认保存的录音覆盖区间可以回听。停止声音会停止当前播报和清空队列，不删除文字。历史补译默认不播报。若回听或播报没有声音，请检查输出设备、音量以及普通话语音是否已安装。

## 翻译与服务

设置分为 **AI 服务、文本翻译服务、文档翻译服务（BabelDOC）**。三者默认分别保存 Key、提供商和模型；同一提供商也可以配置不同 Key。文本和文档服务可主动勾选“使用相同的 AI 服务”，共享主 AI 的提供商、模型及 Key；取消勾选后恢复各自独立设置。

支持 **Google Gemini（AI Studio Key）、DeepSeek、OpenAI 兼容 API、OpenAI**。Google Key 在 [AI Studio](https://aistudio.google.com/apikey) 创建，使用 Gemini Developer API；旧 Cloud Express Key 不会被当作 AI Studio Key 复用。模型栏可填写账户可用的模型 ID。OpenAI 兼容服务还需填写 Base URL（例如服务商提供的 `/v1` 地址），先保存模型/地址，再保存 Key 或测试连接。更换兼容接口地址需单独配置该地址的 Key。

保存设置及切换服务不会自动测试；只有明确点击测试才会发送连接请求。每次请求固定所选模型和配置，已发请求继续使用原配置。应用运行期间，已启动且未暂停的课堂任务会继续处理；重启不自动恢复音频采集，迁移或备份恢复的任务保持暂停。文件任务固定原件、语言、领域与术语快照。

文本翻译支持英语/日语到简体/繁体，领域和自定义术语。术语可新建、编辑、开关、导入及导出，并选择文本工具或课程范围。课堂转写面板可明确启用课程术语，使用固定保存版本；术语编辑后需主动更新课堂快照，已派发请求及其重试保留原快照。文件翻译独立选择术语范围，支持仅译文与双语输出、任务历史、预览、另存、取消和重试。翻译依赖真实服务；本地契约测试不代表实际译文质量。

文件翻译的引擎选项为“自动 / BabelDOC / 内置引擎”。自动模式下 PDF、PPT、PPTX 使用随应用打包的 BabelDOC；幻灯片先在本地转换为 PDF。Markdown、文本与块笔记默认使用内置引擎，以保留可编辑的伴随输出；也可手动选择 BabelDOC 输出 PDF。BabelDOC 支持仅译文或原文/译文交替页双语 PDF，使用“文档翻译服务”中选择的 Key、模型及术语。Google 通过官方 OpenAI 兼容接口供 BabelDOC 调用；不需要另外注册中转服务。取消会停止本地引擎，已发送请求仍可能计费；BabelDOC 的重试会重新处理整个文件。旧内置引擎任务沿用原管线，不会混用处理版本。

## 数据位置与迁移

- 应用索引：`~/Library/Application Support/ULecture/Workspace`。
- 新建课程资料：`~/Library/Application Support/ULecture/Courses/<UUID>`，与应用索引的 `Workspace` 目录同级。已有课程、迁移及恢复的课程保留各自登记的存储位置；侧车数据位于课程目录的 `.ulecture/documents/<稳定ID>`。
- 语音会话：默认 `~/Documents/ULecture/Transcripts`（通过系统文档目录 API 解析）；当前实际目录显示在设置中，每个会话自动保存 `transcript.txt` 与 `transcript-bilingual.txt`，另保留用于恢复的内部会话数据库；启用录音时，音频也保存在会话目录内。变更根目录使用校验、快照及恢复日志，旧根保留。
- 文本/文件任务：`~/Library/Application Support/ULecture/TextTranslation` 与 `FileTranslation`。
- 模型：资源随包提供，运行缓存沿用 `~/Library/Application Support/UwayClassroom/Models` 以兼容旧安装，由模型管理器校验和恢复；界面报告缺失或损坏，不能用模型文件“存在”替代就绪。

旧库迁移前先关闭仍在写入该库的旧版应用；活动写入者会阻止迁移，原库继续保留。迁移先冻结一致快照，保留原库、原ID、原 Markdown 和全部历史。迁移中断可重试；新预检生成独立快照，不覆盖已经导入后的编辑。旧课程选择真实目标目录后，资料复制并核对，再发布新的路径映射。回退旧版本前应使用保留的原库，不能让旧程序直接打开新格式工作空间。

## 导出和备份

“转写与译文（含字幕）”是统一入口，可选仅原文或原译文，并导出 TXT、Markdown、SRT、VTT。字幕保留实际时间间断；没有内容不会生成空成功结果。笔记与 PDF 的资料导出在各自编辑器内。

设置中的备份选择课程/课堂/资料，按引用闭包收集跨目录原件、批注、笔记历史及资源、AI来源快照、转写/翻译和已完成录音。凭据、模型、系统书签和原始绝对课程路径不包含在可移植包中。

新 `.ulbackup` 恢复前完整验证，再在所选目标下建立新课程目录和新身份。真实进程中断后可用同一源及目标重试，不覆盖已有冲突文件。旧 `.uwaybackup` 先在隔离暂存区验证和转换，再进入同一恢复链路。恢复的云任务处于暂停/中断状态，不会自动发送请求。

## 保存状态与旧数据升级

两份 TXT 从同一已保存状态生成。确认原文被修订后，原段落更新；旧修订的译文不会配给新原文。翻译未完成时双语文件保留原文，译文到达后补入。本地临时识别草稿仅供阅读，未确认前不会作为永久原文保存。

在线服务可能提供互不关联的原文和翻译流。没有可靠关联 ID 时，文件按真实接收顺序注明轨道；不能把相邻两条字幕理解为精确逐句配对。未完成或被中断的在线片段会标记状态。

两份固定文件无法在文件系统中同时完成两次替换；若中途失败，界面会显示保存未完成，并保留可恢复的同代状态。修复磁盘或保存位置后点击重试，或重新打开应用恢复。应用不会在只有一份成功时显示全部已保存。保存失败会停止继续采集，防止未保存内容积累。

旧版双语 `transcript.txt` 转换前，原始字节保存至会话目录的 `text-recovery` 恢复区域，并使用内容哈希命名。外部修改的 TXT 也保留必要恢复副本。不要手动删除正在修复的会话数据库、临时发布记录或恢复副本。数据库缺失或损坏时，保留旧文件，不凭猜测拆分原文和译文。

## 连续字幕

原文与译文各自的行数以实际排版为准：一个长句折成三行就占三行。四行窗口显示 A、B、C、D，新增 E 后显示 B、C、D、E。流式修订原位更新，后续确认不会重播已离开的旧行。

调整宽度、字号、行数或上下顺序后字幕重新排版，保留合理阅读位置。两种语言自然折行，不用空格强行对齐。关闭某个轨道仅隐藏其显示。字幕只保留有限显示缓存；完整历史仍在会话中。系统“减少动态效果”会关闭上移动画，滚动语义不变。

## 使用限制

云功能取决于提供商账户、区域、模型和网络。识别、翻译及 AI 答复可能出错，尤其在重叠发言、噪声、专有名词或扫描质量较差时，应回看原始材料。实际测试范围与未覆盖环境见仓库根目录 [VALIDATION.md](../../VALIDATION.md)。当前发行包没有 Apple 公证，安装说明见 [README](../../README.md)。
